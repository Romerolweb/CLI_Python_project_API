## Task 1 Display Menu
Your first task is to develop a menu that provides the following choices:
a. Print help menu
b. Exit the program
- Create a new folder for your project named, for example, 
coit20245_prog_fun_ass2_wildlife
- Open the folder in VSCode and create a new file named sighting.py
- Write a display_menu() function that uses print to display your menu. The following 
is a simulated run of the application you will develop.
Help
====
The following commands are recognised.
Display help wildlife> help
Exit the application wildlife> exit
- Debug your display_menu() function by adding in a call to the function. Remove the 
call once you have completed debugging the function. 
- Document each function as you develop.
